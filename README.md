# 체육교사 보조 프로그램 · 웹판 v1.5.0

이 저장소는 프로그램의 **새 버전 알림 원본**입니다. 각 학교 프로그램이 manifest.json 을 읽어 "새 버전 · 라이브러리 버전 N" 을 알립니다. 코드 파일은 관리자가 원본(라이브러리) 스크립트에 붙여 넣을 때 쓰는 사본이고, shell/ 은 각 학교 시트에 넣는 껍데기입니다.

- 버전: 1.5.0 (2026-09-18)
- 파일 28개

v1.5.0
- 스포츠클럽 교내 리그전: 클럽 활동과 따로 도는 학교 전체 리그. 회차(1학기·2학기) 안에 종목을 여러 개 두고, 종목마다 대상·방식(리그전/기록 경기)·참가 단위(반 대항/선수·팀)와 참가 명단(학생 명단에서 고르기)을 따로 둡니다

- 회차 시상 요약과 교사 홈 진행 카드, 계획서용 일정표·결과 순위표·게시용 대진표(인쇄·Word)
