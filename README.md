# 체육교사 보조 프로그램 · 웹판 v1.4.0

이 저장소는 프로그램의 **새 버전 알림 원본**입니다. 각 학교 프로그램이 manifest.json 을 읽어 "새 버전 · 라이브러리 버전 N" 을 알립니다. 코드 파일은 관리자가 원본(라이브러리) 스크립트에 붙여 넣을 때 쓰는 사본이고, shell/ 은 각 학교 시트에 넣는 껍데기입니다.

- 버전: 1.4.0 (2026-09-18)
- 파일 28개

v1.4.0
- 수행평가 상호평가: 평가마다 켜고 끄기(짝은 학생이 고르거나 선생님이 배정), 짝이 기준 체크 + 한마디 + 사진·영상 → 선생님이 보고 단계 반영. 학생에게는 진행 상태와 짝이 찍어 준 사진·영상만 보이고 단계·특기사항은 비공개
- PAPS 기록 입력: 엑셀·한글 표 붙여넣기로 여러 종목·여러 반 한 번에 저장 (머리글 자동 인식, 열 맞추기 미리보기)
- 학생 프로필·홈·명단·설정 등 공통 화면이 색상 테마를 따르도록 수정
- 불러오는 중 로그아웃하면 나던 'Cannot set properties of null' 오류 수정
