# 체육교사 보조 프로그램 · 웹판 v1.7.0

이 저장소는 프로그램의 **새 버전 알림 원본**입니다. 각 학교 프로그램이 manifest.json 을 읽어 "새 버전 · 라이브러리 버전 N" 을 알립니다. 코드 파일은 관리자가 원본(라이브러리) 스크립트에 붙여 넣을 때 쓰는 사본이고, shell/ 은 각 학교 시트에 넣는 껍데기입니다.

- 버전: 1.7.0 (2026-09-23)
- 파일 28개

수업 도우미에 팀·모둠 짜기 추가: 성별·체력(PAPS 등급)이 고르게 섞이도록 팀 수 또는 모둠 인원으로 나누기, 조건(꼭 같은 팀·같은 팀 금지·주장), 끌어서 옮기기, 저장·인쇄, 학생 화면에 우리 팀 카드.
