# 체육교사 보조 프로그램 · 웹판 v1.5.2

이 저장소는 프로그램의 **새 버전 알림 원본**입니다. 각 학교 프로그램이 manifest.json 을 읽어 "새 버전 · 라이브러리 버전 N" 을 알립니다. 코드 파일은 관리자가 원본(라이브러리) 스크립트에 붙여 넣을 때 쓰는 사본이고, shell/ 은 각 학교 시트에 넣는 껍데기입니다.

- 버전: 1.5.2 (2026-09-18)
- 파일 28개

v1.5.2
- 교내 리그전 참가 단위를 세 가지로 나눴습니다: 반 대항 / 팀 대항 / 개인전
  · 반 대항 — 참가 수만 넣으면 1반, 2반… 이 자동으로 생기고 옆 칸에 담임
  · 팀 대항 — 팀 이름을 적고 사람 단추로 주장을 학생 명단에서 고르기
  · 개인전 — 참가 학생을 학생 명단에서 한꺼번에 고르기
- 종목 '직접 입력' 칸에서 예시 목록(자동완성)이 떠 가리던 것을 없앴습니다
- v1.5.1 의 종목 목록 고르기·대상 학년 체크가 함께 들어 있습니다
