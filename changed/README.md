# 체육교사 보조 프로그램 · 웹판 v1.5.1

이 저장소는 프로그램의 **새 버전 알림 원본**입니다. 각 학교 프로그램이 manifest.json 을 읽어 "새 버전 · 라이브러리 버전 N" 을 알립니다. 코드 파일은 관리자가 원본(라이브러리) 스크립트에 붙여 넣을 때 쓰는 사본이고, shell/ 은 각 학교 시트에 넣는 껍데기입니다.

- 버전: 1.5.1 (2026-09-18)
- 파일 28개

v1.5.1
- 교내 리그전 종목을 목록에서 고르도록 바꿨습니다 (게임형 수업 종목 + 스포츠클럽 종목, 맨 위 '직접 입력…'을 고르면 이름을 직접 적을 수 있습니다)
- 종목의 대상은 '전교' 또는 학년 체크로 자동 입력됩니다 (예: 5·6학년)
